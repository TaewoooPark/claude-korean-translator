Claude KO↔EN Translator

claude.ai에서 한국어로 쓰면 영어로 전송하고, Claude의 영어 응답을 한국어로 보여줍니다. 번역은 본인 Anthropic API 키로 Claude Haiku를 호출해 처리합니다.

보안 안내
• API 키는 이 브라우저의 확장 저장소(chrome.storage.local)에만 보관되며, 제3 서버로 전송되지 않습니다.
• 텍스트는 오직 api.anthropic.com 으로만 전송됩니다. 과금은 본인 키로 이루어집니다.

8.1 트러블슈팅
• 401 ... CORS requests are not allowed for this Organization: Anthropic Console 조직 설정에서 클라이언트/직접 브라우저 접근(CORS)을 허용해야 합니다.
• 401 authentication_error: 키 오타·비활성·크레딧 부족.
• 429: 레이트리밋 — 잠시 후 재시도.
